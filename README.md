# Frontend_lopputyö
Olen Home.jsx lisännyt useState hookin, jotta sain eri napit toimimaan onClickin kanssa ja viemään tiettyyn paikkaan. function home sulkujen sisällä on työkaluja jotka tulevat home.jsx:stä. page on se joka käyttää home näkymää alussa ja sitten, kun painaa nappia niin se vaihtaa näkymää. setPage päivittää pagea. Navigointi classissä määritetään miltä sivu näyttää ja mitä tapahtuu kun nappeja painetaan.  Create note painike tarkistaa onko kursseja jos ei niin tulee alertti. Sen alapuolella olevat constit katsoo milloin nappia painetaan ja ne kutsuu setpagen ja vaihtaa pagen siihen. content classissa se katsoo onko page sama mikä määrittelyssä on ja jos on niin näyttää sen componentin sisällön. Home.css olen laittanut että home palkki on vain vasemmalla puolella ja siellä näkyy napit allekkain ja keskellä.

App.jsx alussa on importit ja sitten on kaksi useState hookkia courses on lista kursseista ja notes on lista muistiinpanoista, jotka ovat aluksi tyhjiä. Sitten luodaan uusi kurssiobjekti jolle luodaan id ja nimi. Päivittää tilan ja lisää newcourseihin uuden kurssin. viimeinen return on sitä varten että pystytään heti käyttää muualla. OnSave on muistiinpanojen tallennusta varten. Se luo jokaiselle muistiinpanolle oman aikaleiman id tunnukseksi. Lisää uuden muistiinpanon olemassa olevaan notes listaan. OnDelete on muistiinpanojen poistamista varten filter käy läpi koko listan ja poistaa vain sen jonka id on sama kuin mikä halutaan poistaa. setNotes päivittää listan niin, että poistettua ei enää ole näkyvissä. Viimeisessä parent kutsuu Home.jsx eli lapsea ja antaa sille työkaluja jota tarvitaan toimittavaksi.

Create.jsx alussa on importit. Määritellään useState tekstiä sen pitäisi pitää tekstin sisällä jonka käyttäjä kirjoittaa. Alku arvo on tyhjä. setTekstiä päivittää tekstiä. handleClick kutsutaan kun painetaan save nappia. Siinä on async joka saattaa sisältää tai kutsua promisea palauttavan funktion. handleChange funktio kutsutaan, kun kirjoitetaan textareahan ja e.target asettaa tekstiä tilan uudeksi arvoksi setTekstiä funktiolla. textarea on syöttökenttä. value varmistaa, että kentän sisältö vastaa tilamuuttujaan tekstiä. onChange kutsuu handlechangea ja kirjottamalla päivitetään tilaa. Savea kun painetaan handleclick suoritetaan. Create.css on teksti keskellä ja tekstin heigth and width määritetty.

AddCourses.jsx importit alussa. useState tekee samaa mitä aikaisemmin mutta newcourse on käyttäjän kirjoittamaa tekstiä varten ja message on palauteviestiä varten. handleAddCourse trim poistaa alusta ja lopusta olevat ylimääräiset välilyönnit. varmistaa syötteen olevan enemmän kuin 0 kirjainta. Se luo kurssiobjektin. Seuraava tyhjentää syöttökentän. sitten luodaan onnistunut viesti jossa näkyy kurssin nimi ja id. handlechange päivittää tilan ja tyhjentää message kentän jotta edellinen teksti katoaa. Divien sisällä on input jonka type on tekstiä, value on newcoursename ja se päivittyy handlechangella. Nappi käynnistää handleAddCoursen. Message näyttää tekstiä jos on virheellinen syöttö tai syöttö on toiminut.

Listnotes.jsx const usestatessa on suodatusta varten ja jos sen arvo on tyhjä kaikki tallenetut muistiinpanot näkyvät. Seuraava on filteröintiä joka käyttää filter() metodia jonka kanssa verrataan kurssi Id:tä valittuun Id:hen. Number() varmistaa vertailun toimivan vaikka olisi numeroita ja tekstiä. Jos ei ole valittu mitään näyttää kaikki muistiinpanot. Label laittaa tekstin näkyviin ja sitten tulee select joka on alasvetovalikko. Value arvoon on annettu suodataId tilaan ja kun se vaihtuu niin setSuodataId vaihtuu. Option value on tyhjä joka näyttää että suodatusta ei ole valittu oletetusti. .map käy läpi courses taulukon ja luo niistä valinnan valikkoon. Key osassa on uniikki avain jotta tietää mikä elementti on mikäkin. Value kun kurssin valitsee, valikon arvoksi tulee kurssin Id. k.name näytetään kurssin nimi. Seuraavaksi jos ei ole muistiinpanoja niin näkyy ei muistiinpanoja. Jos on niin luodaan niistä lista .map käy jokaisen listaolion m läpi ja muuntaa ne listamerkiksi <li>. Niissä näytetään kurssin nimi, id, aika ja päivämäärä ja myös teksti. Niiden alle luodaan delete nappi jonka kanssa voidaan poistaa muistiinpano.
